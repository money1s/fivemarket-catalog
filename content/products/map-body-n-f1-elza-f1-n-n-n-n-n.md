Томат **Ельза F1 (Elza F1)** — ранній індетермінантний гібрид томата типу **“сливка”** для вирощування переважно в **закритому ґрунті**. Формує вирівняні щільні плоди червоного кольору, які **не дрібнішають протягом сезону**, добре зав’язуються навіть за **високих температур** і довго зберігають товарний вигляд, тому гібрид зручний для продажу та транспортування. 

**Основні характеристики:**

• **Тип рослини:** Індетермінантний (високорослий), переважно для закритого ґрунту. 

• **Дозрівання:** Ранній — часто вказують **65–70 днів від висадки розсади** (у частині описів також зустрічається **~100 днів** як термін дозрівання). 

• **Форма:** Сливовидна (“сливка”). 

• **Колір:** Червоний. 

• **Вага:** Зазвичай **120–140 г** (в окремих продавців можуть вказувати “до 200 г”). 

• **Китиця:** На китиці формується **6–8 вирівняних плодів**. 

• **Щільність/шкірка:** Плоди щільні, **не розтріскуються**, довго зберігають товарний вигляд (часто вказують **до 3 тижнів**), добре транспортуються. 

**Вирощування:**

Рекомендований для **теплиць/закритого ґрунту**. Потребує підв’язки та формування; для стабільної якості плодів бажані рівномірний полив і регулярне живлення. Гібрид відзначають здатністю добре зав’язувати плоди за високих температур. 

**Стійкість до** **фузаріозного в’янення**, **фузаріозної гнилі кореня**, **вірусу мозаїки томату**, **жовтого скручування листя (TYLCV)** та **нематод**. 

**Ідеальний для:** Продажу/свіжого ринку, салатів, кулінарії; завдяки щільності підходить для транспортування та зберігання.
