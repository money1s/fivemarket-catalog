Томат **Брісколіно F1 (Briscolino F1)** — ранній детермінантний гібрид коктейльного томата типу **міні-сливка**. Формує багато дрібних, дуже вирівняних **червоних** плодів, які **щільні, солодкі та добре тримають форму** — не мнуться і рідше тріскаються. Завдяки насиченому смаку та високій якості плодів підходить і для **свіжого споживання**, і для **цільноплідного консервування** та різної переробки.

**Основні характеристики:**

• **Тип рослини:** Детермінантний (компактний кущ).

• **Дозрівання:** Ранній, орієнтовно 88–95 днів (залежить від умов).

• **Форма:** Міні-сливка / подовжена коктейльна “сливка”, вирівняна.

• **Колір:** Насичено-червоний.

• **Вага:** У середньому 20–25 г (у різних умовах може бути більший).

• **Щільність/шкірка:** Плоди дуже щільні, стійкіші до розтріскування, добре транспортуються.

• **Смак:** Солодкий, насичений (високий рівень цукрів).

• **Вирощування:**

Підходить для **відкритого ґрунту** та під **плівковими укриттями/в теплицях**. Для максимальної вирівняності плодів бажані регулярний полив і частий збір.

• **Стійкість:** До **вертицильозного в’янення**; до **фузаріозного в’янення** (раси 0–1); до **бактеріальної крапчатості/плямистості**; до **вірусу бронзовості томата (TSWV)**; інколи додатково зазначають стійкість до **нематод.** 

**Ідеальний для:** Свіжого ринку, салатів, перекусу, цільноплідного консервування, переробки.
