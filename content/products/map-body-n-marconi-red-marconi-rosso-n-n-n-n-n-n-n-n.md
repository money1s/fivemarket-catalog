Перець солодкий **Марконі Ред (Marconi Red / Marconi Rosso)** — це класичний італійський довгоплідний сорт солодкого перцю з дуже ароматними, солодкими плодами, які дозрівають від **темно-зеленого до насичено-червоного**. Плоди видовжені, конічні, зручно ріжуться смужками, чудово підходять для **смаження, запікання, грилю та маринування**, а також для свіжих салатів — саме за це Марконі часто вважають одним із найкращих “італійських” перців. 

**Основні характеристики:**

• **Тип рослини:** Солодкий перець (сорт), рослина сильноросла, зазвичай 60–75 см. 

• **Дозрівання:** Середньоранній, приблизно 70–90 днів від висадки розсади (залежить від умов). 

• **Форма плодів:** Довгі конічні/видовжені “італійські” плоди, часто 2–3 лопаті. 

• **Колір:** Темно-зелений у технічній стиглості → насичено-червоний у біологічній. 

• **Розмір:** Зазвичай 19×6 см або 6–8″ (15–20 см), у добрих умовах може бути значно довшим. 

• **М’якоть:** Соковита, солодка; стінка зазвичай середня (для італійського типу). 

• **Смак:** Дуже солодкий, насичений, без гіркоти; особливо смачний після термообробки. 

**Вирощування:**

Підходить для відкритого ґрунту та теплиць/укриттів. Для максимальної довжини плодів бажані повне сонце, регулярний полив без пересушування та підживлення; кущі з великим урожаєм краще підв’язувати. 

**Стійкість до** основних стресів сезону (зокрема спеки) та загальна витривалість/надійність у вирощуванні (специфічний “пакет” хвороб зазвичай не прописують для цього сорту). 

**Ідеальний для:** Смаження, запікання, грилю, салатів, маринування та кулінарії замість болгарського перцю.
